# 打鍵カウンタの導入方法 — 通常の手順

## 1. ダウンロードして展開する

[最新版のReleaseページ](https://github.com/dj-kata/inf_daken_counter_obsw/releases/latest)を開き、
注意事項を確認してから `inf_daken_counter.zip` をダウンロードします。
ZIPを展開し、`notes_counter.exe` や `template` フォルダを含む一式を同じ場所に置いてください。
Pythonのインストールは不要です。

OneDriveによる同期の対象外のフォルダを使ってください。同期によって設定やデータが巻き戻ることを避けられます。

## 2. INFINITASを準備する

打鍵カウンタは、INFINITASを動かすWindowsの64bit環境で実行します。
キャプチャボードで映像を受け取る配信用PCではなく、ゲーム用PCに置いてください。
ゲーム画面は1920×1080を基準に認識します。

月間ノーツ数などの集計に必要な判定情報を取得するため、
INFINITASのプレー設定（Start → E2）で「判定の数リアルタイム表示」を有効にします。

## 3. 起動して画面取得を確認する

1. 展開したフォルダの `notes_counter.exe` を起動します。
2. 「ファイル」→「基本設定」→「機能設定」を開きます。
3. 「ゲーム画面取得」は、まず初期値の「直接取得(DXCAM)」を使います。
4. ゲームを表示し、メイン画面の「ゲーム画面取得状態」と「現在のモード」がゲーム画面に追従することを確認します。
5. 1曲プレーして、打鍵数やリザルトが記録されることを確認します。

直接取得で使う場合、OBSの起動やWebSocket接続の設定は必要ありません。
画面を取得できない場合は、ゲームが起動しているか、他のウィンドウに隠れていないかを確認し、
「直接取得(旧方式)」への切り替えも試してください。

## OBS経由でゲーム画面を取得する場合

直接取得が重い場合などは「OBS WebSocket経由」も使えます。
OBS 28以降を使い、[OBSとの接続](obs-control.md#obs-connection)を設定してください。
続いて同じページの[監視対象ソースの指定](obs-control.md#monitor-source)を行い、
「機能設定」の「ゲーム画面取得」を「OBS WebSocket経由」に切り替えます。
監視対象には、装飾や配信レイアウトではなくINFINITASのゲーム映像を指定してください。
