# 打鍵カウンタの導入方法 — 通常の手順

## 1. ダウンロードして展開する

[最新版のReleaseページ](https://github.com/dj-kata/inf_daken_counter_obsw/releases/latest)を開き、
注意事項を確認してから `inf_daken_counter.zip` をダウンロードします。
ZIPを展開し、`notes_counter.exe` や `template` フォルダを含む一式を同じ場所に置いてください。
Pythonのインストールは不要です。

OneDriveによる同期の対象外のフォルダを使ってください。同期によって設定やデータが巻き戻ることを避けられます。

### 更新する場合

アプリ内の自動更新は、ダウンロード・展開後にアプリを終了し、別のウィンドウでファイルを置き換えます。
コピーが成功すると自動で再起動します。失敗した場合は再起動せず、アプリのフォルダに
`update_install.log` と展開済みの `tmp` フォルダを残します。

旧版の自動更新では、使用中のDLLが置き換わらず、更新後にQtMultimediaなどのImportErrorが出る場合があります。
この更新処理の修正版を初めて導入する場合や、すでに起動エラーが出ている場合は、次の手順で手動更新してください。

1. アプリをすべて終了し、使用中のフォルダをバックアップします。
2. 最新版ZIPを別の空フォルダに展開し、起動できることを確認します。
3. 起動確認用のアプリも終了し、展開した一式を元のアプリのフォルダへ上書きコピーします。`lib` フォルダも含めてください。
4. 元のフォルダの `notes_counter.exe` を起動します。既存の設定やプレーデータは削除しないでください。

## 2. INFINITASを準備する

打鍵カウンタは、INFINITASを動かすWindowsの64bit環境で実行します。
キャプチャボードで映像を受け取る配信用PCではなく、ゲーム用PCに置いてください。
ゲーム画面は1920×1080を基準に認識します。

Wikiに掲載されている動作環境の一例は次のとおりです。必要スペックの下限ではありません。

| 項目 | Wiki掲載の環境 |
| --- | --- |
| OS | Windows 11 64bit（25H2） |
| CPU | Intel Core i7-12700F |
| GPU | NVIDIA RTX 5060 |
| ウイルス対策 | Windows Defender |
| OBS | 32.0.1（OBS経由の取得・自動制御を使う場合は28以降） |

月間ノーツ数などの集計に必要な判定情報を取得するため、
INFINITASのプレー設定（Start → E2）で「判定の数リアルタイム表示」を有効にします。

## 3. 起動して画面取得を確認する

1. 展開したフォルダの `notes_counter.exe` を起動します。
2. 「ファイル」→「基本設定」→「基本設定」を開きます。
3. 「ゲーム画面取得」は、まず初期値の「直接取得(GDI)」を使います。
4. ゲームを表示し、メイン画面の「ゲーム画面取得状態」と「現在のモード」がゲーム画面に追従することを確認します。
5. 1曲プレーして、打鍵数やリザルトが記録されることを確認します。

直接取得で使う場合、OBSの起動やWebSocket接続の設定は必要ありません。
画面を取得できない場合は、ゲームが起動しているか、他のウィンドウに隠れていないかを確認し、
「直接取得(DXCAM)」への切り替えも試してください。

OBSを使う場合は、[Spout2プラグインによる取得](capture.md#spout)も利用できます。
プラグインの導入、Spout Filterの追加、送信名の指定を順に説明しています。

## OBS経由でゲーム画面を取得する場合

直接取得が重い場合などは「OBS WebSocket経由」も使えます。
OBS 28以降を使い、[OBSとの接続](obs-control.md#obs-connection)を設定してください。
続いて同じページの[監視対象ソースの指定](obs-control.md#monitor-source)を行い、
「基本設定」の「ゲーム画面取得」を「OBS WebSocket経由」に切り替えます。
監視対象には、装飾や配信レイアウトではなくINFINITASのゲーム映像を指定してください。
