# ライバル登録

ライバルのCSVを登録すると、[スコアビューワ](score-viewer.md)や[OBSのライバル欄ビュー](obs-views.md)で比較できます。

## ライバルのCSVを登録する

1. ライバルに `inf_score.csv` をGoogle Driveへ置いてもらい、共有URLを受け取ります。
2. 共有範囲は、ログインしなくてもリンクからファイルを取得できる状態にしてもらいます。
3. 「ファイル」→「基本設定」→「ライバル」を開きます。
4. 「名前」に表示名、「URL」にCSVの共有URLを入力して「追加」を押します。
5. 「OK」で適用し、スコアビューワで取得したスコアを確認します。

名前はスコアビューワと `rival.html` に表示されます。不要になった登録は、一覧の行を選択して「削除」で外せます。
AC版のe-amusement形式のスコアCSVも読み込めます。

## 自分のCSVを共有する

打鍵カウンタを終了すると、自己ベストを `inf_score.csv` に出力します。
「基本設定」→「ライバル」の「CSV出力先」でフォルダを指定できます。空欄の場合はアプリのフォルダです。
Google Driveで同期するフォルダを指定すると、出力したCSVを共有に使えます。

共有するのはCSVファイルです。設定ファイルやプレーログを共有する必要はありません。

## スコアを取得できない場合

共有URLを、ログインしていないブラウザでも開けるか確認してください。
権限が足りない場合や、CSVではなくログイン画面が返される場合は取得できません。
