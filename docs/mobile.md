# HTTPサーバ（スマホ連携）

打鍵カウンタの起動中、同じLANにつながっているスマホやタブレットからスコア・プレー履歴を確認できます。
画像の結合や投稿用画像の作成にも使えます。

## スマホで開く

1. 「ファイル」→「基本設定」→「機能設定」で「スマホ用スコア閲覧サーバを起動する」を有効にします。
2. 「スマホ用HTTP port」は通常、初期値の **8787** のままにします。
3. 「OK」で適用し、メイン画面の「スマホ閲覧URL」を確認します。
4. スマホをPCと同じLAN・Wi-Fiにつなぎ、表示されたURLをブラウザで開きます。

例：PCのIPアドレスが `192.168.0.3` なら `http://192.168.0.3:8787/` です。
Windowsでネットワーク通信の許可を求められたら、使用するLANでの通信を許可してください。

複数のネットワークを使っていてURLが合わない場合は、「スマホ用表示NIC」でスマホと同じLANの接続を選びます。
この画面は打鍵カウンタのデータを読むため、アプリを終了すると利用できなくなります。

## スコア・履歴を確認する

トップ画面のフォルダからレベル別の自己ベストやプレー履歴を開き、曲を選んで詳細を確認します。
集計情報や本日の成果もスマホ上で参照できます。

## リザルト画像を選ぶ・結合する {#result-images}

「RESULT IMAGES」やプレー履歴からリザルト画像を選び、複数枚を結合して投稿用画像を作れます。
アプリ起動中に取得した画像は、自動保存の対象でなかったものも利用できます。
画像には[画像保存](image-save.md)で指定したモザイク・カット・統計情報が反映されます。

一時的な画像はアプリ終了後・再起動後には利用できません。
「基本設定」→「画像保存」の「起動中に一時保持するリザルト画像の上限」で、保持枚数を変更できます。
初期値の **0（全件保持）** は起動中の全画像を保持し、100なら直近100枚を保持します。
上限を超えた古い一時画像は削除されます。上限を減らした場合も、適用時に古い画像を削除します。
ファイルとして保存済みの画像は、この上限では削除されません。

## 接続できない場合

- PCとスマホが同じLANにいるか確認します。スマホがモバイル通信になっている場合はWi-Fiへ切り替えます。
- URLのIPアドレスとポート番号を確認します。PC上では `http://127.0.0.1:8787/` でも確認できます。
- アプリが起動中か、サーバ設定が有効か、Windowsのファイアウォールで通信を許可しているか確認します。
