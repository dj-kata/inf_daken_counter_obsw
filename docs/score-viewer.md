# スコアビューワ

記録した自己ベストを一覧で確認し、曲ごとのプレー履歴やライバルのスコアと比較できます。
「ツール」→「スコアビューワ起動」から開きます。

## 曲を探す・履歴を見る

1. SP・DPなどのプレースタイルと、表示するレベルを選びます。
2. 曲名の検索欄で絞り込みます。一覧の列見出しから並び替えもできます。
3. 曲を選ぶと、上部にその曲のプレー履歴とライバル情報が表示されます。

表示される自己ベストは、打鍵カウンタが取得・取り込みしたデータに基づきます。
未登録の曲は、[選曲画面からの登録](features.md#score-import)や保存済みリザルト画像の取り込みで追加できます。

## 誤って登録されたプレーログを削除する

曲を選び、プレー履歴から削除する行を選択して「削除」を押します。
確認画面で曲名・日時・スコアを確認してから実行してください。
削除によって自己ベストが変わる場合があります。

## ライバルと比較する

先に[ライバル登録](rivals.md)でCSVの共有URLを登録します。
曲を選ぶと、ライバル欄でスコアなどを比較できます。
ライバルのCSVが更新され、前回より伸びて自分の自己ベストを超えた譜面は「挑戦状モード」で絞り込めます。
