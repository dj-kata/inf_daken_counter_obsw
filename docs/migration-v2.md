# 打鍵カウンタv2から移行する場合に必要な手順

v2の設定・プレーログを引き継ぎ、OBSに登録したHTMLをv3用へ入れ替えます。

## 1. 元のデータを残して準備する

v2を終了し、使用していたフォルダをバックアップしてください。
設定の `settings.json`、プレーログの `alllog.pkl`、保存済みリザルト画像を残しておきます。

[最新版のReleaseページ](https://github.com/dj-kata/inf_daken_counter_obsw/releases/latest)からZIPをダウンロードし、
[通常の導入手順](install.md)に沿って展開します。
別のフォルダに展開した場合、v2の設定を引き継ぐには `settings.json` を新しいアプリのフォルダへコピーしてください。

## 2. v2の設定を取り込む

`settings.json` がある状態でv3を起動すると、設定をインポートするか確認されます。「はい」を選びます。
OBSの接続先や画像保存先など、一部の設定を引き継げます。
取り込み後の `settings.json` は `settings.json.bak` に名前が変わります。

「ファイル」→「基本設定」で引き継いだ値を確認して「OK」を押します。
OBSを使う場合は「OBS制御設定」も確認してください。
**OBS自動制御のルールは引き継がれないため、[OBS自動制御](obs-control.md)で登録し直します。**

## 3. プレー履歴を取り込む

「ファイル」→「基本設定」→「データ登録」で、次のどちらかを使います。

| 元のデータ | 操作 |
| --- | --- |
| 保存済みのリザルト画像 | 「フォルダから画像を読み込んで登録」で画像のフォルダを選ぶ |
| v2の `alllog.pkl` | 「alllog.pklを選択して登録」でファイルを選ぶ |

リザルト画像が残っている場合は、画像からの取り込みを優先してください。
古いログには曲名などの誤認識が含まれている場合があります。
画像の読み込みは選択したフォルダ直下のPNGが対象です。サブフォルダに分かれている場合は、それぞれ取り込みます。

取り込み終了後、[スコアビューワ](score-viewer.md)で曲名・譜面・スコアを確認します。
誤ったプレーログはスコアビューワから削除できます。
過去のログを統計やプレーログの集計にも含める場合は、「データ登録」の「v2以前のログを集計対象とする」を有効にします。

## 4. OBSのHTMLを入れ替える

v2とv3ではデータの受け渡し方が異なるため、v2のHTMLはそのまま使えません。
OBSのブラウザソースで、新しいアプリの `template` フォルダにあるHTMLを指定し直してください。
設定方法と現在使えるファイルは[OBS向けHTMLビュー](obs-views.md)にまとめています。

最後に1曲プレーし、新しい記録がアプリとHTMLビューに反映されることを確認してください。
