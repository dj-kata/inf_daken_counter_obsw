# OBS自動制御

選曲・プレー・リザルト画面への切り替わりに合わせて、OBSのソース表示やシーンを自動で切り替えられます。
この機能を使う場合は、OBS WebSocketへの接続が必要です。

## OBSとの接続 {#obs-connection}

1. OBS 28以降で「ツール」→「WebSocketサーバー設定」を開き、サーバーを有効にします。
2. OBSに表示されているポート番号とパスワードを控えます。
3. 打鍵カウンタの「ファイル」→「OBS制御設定」を開きます。
4. 同じPCのOBSならホストは `localhost` とし、ポートとパスワードをOBSと一致させます。
5. 「OK」で適用します。接続できない場合はOBSの起動状態と入力値を確認してください。

打鍵カウンタのOBS接続用ポートの初期値は4444ですが、**OBS側の表示を優先して入力**してください。
HTMLビューの「データ表示用port」（初期値8767）とは別の設定です。

## 自動制御のルールを追加する

「OBS制御設定」の「新しい制御設定を追加」で、アクションと実行タイミングを選びます。

| アクション | 指定するもの |
| --- | --- |
| ソースを表示／ソースを非表示 | 対象シーンと対象ソース |
| シーンを切り替え | 切り替え先シーン |
| キャプチャを自動保存 | キャプチャする対象シーンとソース |

タイミングは、アプリの起動・終了、選曲・プレー・リザルト画面の開始・終了から選べます。
「設定を追加」で一覧へ登録し、「OK」で適用してください。

例えば、リザルト画面の間だけ単曲履歴を表示するなら、次の2件を登録します。

- リザルト画面開始時 → 「ソースを表示」→ 単曲履歴のブラウザソース
- リザルト画面終了時 → 「ソースを非表示」→ 同じブラウザソース

HTMLビューをOBSに置く手順は[OBS向けHTMLビュー](obs-views.md)を参照してください。

## 監視対象ソースの指定 {#monitor-source}

ゲーム画面を「OBS WebSocket経由」で取得する場合に設定します。

1. OBSに、INFINITASのゲーム映像を表示するゲームキャプチャソースを用意します。
2. 「OBS制御設定」の「アクション」で「監視対象ソース指定」を選びます。
3. ゲーム映像のある対象シーン・対象ソースを選び、「設定を追加」を押します。
4. 「監視対象ソース」に指定した名前が表示されることを確認し、「OK」で適用します。

直接取得で使う場合は、監視対象ソースの指定は不要です。
OBSのシーン構成を変えた後は、ルールの対象シーン・ソースが合っているか確認してください。
