# その他の機能

## 選曲画面から自己ベストを登録する {#score-import}

「基本設定」→「基本設定」の「選曲画面から自己ベストを登録する」を有効にすると、
選曲画面から自己ベストを取り込みます。
手動で取り込む場合は選曲画面で **F7**、または「ファイル」→「選曲画面から手動登録」を使います。
登録した内容は[スコアビューワ](score-viewer.md)で確認できます。

保存済みのリザルト画像から追加する場合は、「基本設定」→「データ登録」の
「フォルダから画像を読み込んで登録」を使います。選択したフォルダ直下のPNGを読み込みます。

## 本日の成果を投稿する

「ツール」→「成果をツイート」で、打鍵数などの成果を投稿する画面を開けます。
「基本設定」→「追加設定」の「終了時の自動ツイートを有効にする」で、終了時にも投稿画面を開けます。
判定の内訳を含めるかも、同じ場所で選べます。

## その日のプレーログの範囲を変える

「基本設定」→「追加設定」→「データ表示設定」の「本日の成果に含めるオフセット」で、
アプリ起動時刻の何時間前からの結果を本日のログに含めるか指定できます。初期値は4時間です。
PCやアプリを起動し直した後も、その前に記録した結果を表示したいときに調整してください。

## 片手難易度を表示する

「基本設定」→「難易度表」の「片手難易度を表示する」で、SP☆11・☆12の片手難易度を表示できます。
「ツイートのレベル別集計を片手難易度ごとに分ける」で、成果の投稿時の集計も切り替えられます。

## RANDOMレーン配置を認識する

SP・Spout経由の1920×1080映像で利用できます。
ゲーム映像をSpoutで送信し、「基本設定」→「基本設定」で「Spout経由」を選びます。
「Spout送信名」を送信側と一致させ、「RANDOMレーン認識」タブで「RANDOMレーン配置を認識する」を有効にしてください。
初期の送信名は `Spout_OBS_Filter` です。

「配置認識テンプレートフォルダ」にRandomLaneAnalysis_OCRで作成した `templates` フォルダを指定します。
`SCRATCH.png`、`GET_READY.png`、`OP_CURRENT_SCORE.png`、`Op.MIRROR.png`、`Op.RANDOM.png`、`Op.R-.png`、`Op.S-.png` が必要です。
プレー画面の配置オプションとGET READYの表示・消失を認識してから記録・解析を開始します。テンプレート不足・未認識の場合は記録しません。
REGULARまたはMIRRORで譜面を登録します。旧方式の登録データは再登録が必要です。
同じ譜面をRANDOM・R-RANDOMでプレーすると配置を解析できます。
配信に表示する場合は[HTMLビュー](obs-views.md)の `random_lane.html` を使います。

「RANDOMレーン認識」タブの「デフォルト設定を変更する」にチェックすると、検出帯の上端と高さを1P・2P別に設定できます。
初期値は上端55・高さ20pxです。
高さは1〜300pxですが、広げすぎると近接ノーツを区別しにくくなります。
変更は次のプレーから適用され、変更した帯でREGULARまたはMIRRORの再登録が必要です。

## データをバックアップする

アプリを終了してから、アプリのフォルダをコピーしてください。
設定の `config.json`、プレーログの `playlog.infdc`、保存したリザルト画像などを一緒に残せます。
画像保存先やCSV出力先を別フォルダに変えている場合は、そちらもバックアップしてください。
